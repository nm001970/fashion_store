# FORME — Fashion Store Frontend

Static, RTL-first frontend concept for a premium fashion storefront.

## Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4 (configured)
- Custom CSS design tokens

## Current scope
- Visual UI only
- No API
- No backend
- No database
- No real interaction/state
- Mock product data
- Responsive desktop/tablet/mobile layouts
- RTL/Persian-first HTML structure

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
